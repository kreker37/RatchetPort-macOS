# RatchetPort-macOS
RatchetPort macOS Prototype — experimental build to run Ratchet &amp; Clank (PS4) on Apple Silicon. Uses Rosetta 2 for x86‑64 code and Vulkan‑over‑Metal for rendering. Tested on Mac Mini M4: target 60 FPS, hits 12–25 FPS in heavy scenes. Prototype only; not a supported release. Not affiliated with Sony or Insomniac Games
